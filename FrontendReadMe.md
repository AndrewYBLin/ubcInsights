1. In an terminal enter: yarn ts-node src/index.ts  

This get the server up and running

2. Open a new terminal and enter: start frontend/index.html You could also open the index.html file in your web browser.

This opens the webpage and now you can access frontend :\)

Functionalities
- Added datasets are automatically listed
- You can choose the kind of dataset to add
- You can set the dataset ID name
- Bad ID names return an error
- You can remove datasets after adding them
